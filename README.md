Color Clock

A colorful digital clock built with React and Vite. It shows the current time and date,
updates every second, and the card's background color changes to another colour 

Technologies
React (set up with Vite)
date-fns 2.30.0 for formatting the date and time

 How to run locally
1. Clone my repo
2. Go into the project folder through cd color-clock`
3. Install the dependencies: npm install
4. Start the development server: npm run dev
5. Open http://localhost:5173 in your browser in the terminal where the vite is running
